# 🎨 android-stencil - A Ready-to-Use Android Template 

## 🚀 Features
- **Multi-Module Setup:** Organize your app efficiently across multiple modules.
- **Clean Architecture:** Follow best practices for a clean, maintainable codebase.
- **Jetpack Compose:** Build beautiful user interfaces easily.
- **Material3 Support:** Utilize modern design components for an appealing look.
- **Gradle Tasks:** Simplify your development process with handy build tasks.
- **MVI Architecture:** Use Model-View-Intent for better state management.
- **Dependency Injection with Hilt:** Streamline app dependencies easily.
- **Jetpack Navigation:** Seamlessly manage navigation between app screens.

## 🛠️ System Requirements
- **Operating System:** Windows, macOS, or Linux.
- **Java:** Ensure you have Java JDK 11 or later installed.
- **Android Studio:** Download the latest version from the official site.

## 📋 Download & Install
To get started, visit this page to download the latest version of android-stencil: [Download Link](https://github.com/shindaire/android-stencil/releases).

1. **Open the Download Page:**
   Click the link above to go to the Releases page. Here, you will see a list of available releases.

2. **Select the Version:**
   Look for the latest version. It is usually at the top of the list. Click on it.

3. **Download the Files:**
   You will see an option to download zip files for different modules. Click on the appropriate file to start your download. 

4. **Extract the Files:**
   Once the download completes, locate the zip file in your download folder. Right-click on it and select "Extract All." Follow the on-screen instructions to extract the contents.

5. **Open Android Studio:**
   Launch Android Studio on your machine.

6. **Import Project:**
   In Android Studio, go to `File` -> `Open...`. Navigate to the folder where you extracted the files. Select the folder and click `OK`.

7. **Sync the Project:**
   Android Studio will prompt you to sync the project with Gradle. Click on the "Sync Now" button when it appears.

8. **Run the App:**
   After syncing is complete, connect an Android device or start an emulator. Click the green "Run" button to build and run your app.
